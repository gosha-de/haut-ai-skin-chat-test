# Brands using Haut.AI

Searched 18 Nov 2026. No live Skin.Chat install on a brand site could be found publicly. Brand sites do run Haut.AI's other tools.

Our prototype uses made-up brands. Real brands stay out of it. We looked at them for two things.

## 1. Style check: can our brand settings fit very different brands?

Two brands that look as different from each other as possible:

| Brand | Look | Also worth noting |
|---|---|---|
| [Nuban Beauty](https://nubanbeauty.com/) | Dark, minimal, red accent, wide-spaced capitals | Runs Haut.AI's older Skin Consultant as a floating "Free AI skin analysis" button, next to a separate support chat. Two chat buttons compete for attention |
| [2250](https://2250.care/) | Warm orange gradient, techy font, product photography | Uses Haut.AI's selfie capture for a "60-second AI scan" that leads to a routine picked up at a pharmacy |

Screenshots: `nuban-beauty-home.jpg`, `nuban-beauty-two-chats.jpg`, `2250-home.jpg`.

## 2. Idea: saved history as a reason to sign up

[Olay Skin Advisor](https://www.olay.com/skin-advisor) uses Haut.AI's selfie capture. Its popup reads: "Join Club Olay to save 25% or more and securely store your analysis history". A big brand already uses saved history as the reason to create an account.

Screenshot: `olay-skin-advisor.jpg`.

## What Haut.AI's docs say about Skin.Chat on brand sites

- Brands add it as a full chat on a page, or as a floating button that opens it.
- The brand can pass its **customer ID**, so a logged-in shopper is recognized on any device. That matters for our returning user.
- "Add to cart" in the chat can add to the shop's real cart.

Source: [Skin.Chat website integration guide](https://docs.saas.haut.ai/haut.ai/haut.ai-features/skin.chat/website-integration-guide).

## Limits

The search tools we could use without an account only show recent sites, and some tools load only after a click. "Not found" doesn't mean nobody uses Skin.Chat. Asking Haut.AI is the reliable way to get real examples.
